# Trempl1

Dépose ton CV, découvre les offres qui te correspondent et génère ta lettre de motivation ou ton message au recruteur en un clic.

**Statut :** prototype de démonstration. Les offres, l'analyse du CV et les textes générés sont simulés.

## Contenu

- `index.html` : tout le site (React chargé depuis un CDN, aucune installation nécessaire)
- `netlify.toml` : configuration de l'hébergement Netlify

## Voir le site en local

Double-cliquer sur `index.html`.

Pour tester l'écran d'erreur de lecture du CV, ajouter `?cvError` à la fin de l'adresse.
